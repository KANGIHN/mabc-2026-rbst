# MABC 2027 데모 시나리오 — 백엔드 구성 및 시연 참조

> 이 파일은 2026-09-13 세션에서 백엔드에 반영한 MABC 2027 데모 시나리오 데이터를 정리한 참조 문서다.
> 제출 서류에 레포 링크를 포함할 때, 심사·재현 관점에서 "어떤 데모 데이터가 어디에 있고 어떻게 카드로 이어지는지"를 설명하는 용도다.

---

## 1. 개요

- **목적**: MABC 2027 관련 질문(진행 중 / 대기 중 / 충돌 및 (test) 변형)을 입력했을 때, 서비스 MVP가 실제 로직 흐름(입력 → 처리 상태 → 카드 출력, 상태 판정 → 첫 행동 → 주의사항 + 근거, 충돌 처리)을 데모 모드로 보여줄 수 있게 백엔드에 시나리오 데이터를 구성함.
- **범위**: 백엔드 `api/generate.js`의 `buildDemoResult(query)` — `demoMap` 내 MABC 2027 키 3종 + (test) 계열 질문 매핑.
- **표시 원칙**: 데모 모드면 "데모 예시" 표지와 함께 실제 로직 흐름이 보이도록 구성(단순 정적 예시 카드 노출이 아님). 근거(reason)에는 실제 Google 캘린더·Drive 기록 인용.

## 3. MABC 2027 데모 시나리오 3종

### 3-1. "MABC 2027 진행 중"
- **상태**: 진행 중
- **kind**: 검토/의사결정 대기 업무
- **stateText**: 기획안 초안은 작성했고, PRD 리뷰(9/15)와 제출 마감(9/16 18:00)을 앞두고 있어요. 캘린더에 기획 회의·PRD 리뷰·멘토 미팅 일정이 잡혀 있고, 드라이브에 기획안 초안·9월 회의 메모·진행 현황·업무 추적 파일이 정리돼 있어요.
- **action.line**: PRD 리뷰(9/15) 준비 — 기획안 초안을 PRD 형식으로 정리해서 리뷰에 가져가세요.
- **action.reason**: 캘린더에 PRD 리뷰 일정이 잡혀 있고, 기획안 초안이 이미 드라이브에 있어서 다음 단계로 연결돼요.
- **warn**: 제출 마감 9/16 18:00 KST — PRD 리뷰(9/15) 후 반영 시간이 촉박할 수 있어요. 리뷰 결과를 빠르게 반영할 수 있게 준비해 두세요.
- **reason**: 캘린더: 기획 회의(9/10)·PRD 리뷰(9/15)·제출 마감(9/16)·멘토 미팅(9/17) / 드라이브: 기획안 초안·9월 회의 메모·진행 현황·업무 추적

### 3-2. "MABC 2027 대기 중"
- **상태**: 대기 중
- **kind**: 검토/의사결정 대기 업무
- **stateText**: 기획안 초안은 작성했지만, PRD 리뷰(9/15)에서 피드백을 받아야 다음 단계로 갈 수 있어요. 제출 마감(9/16 18:00)이 가까워지고 있어서, 피드백 도착 시점과 반영 시간을 감안해야 해요.
- **action.line**: PRD 리뷰(9/15) 전에 기획안 초안을 다시 한 번 점검하고, 리뷰 후 피드백을 바로 반영할 수 있게 정리해 두세요.
- **action.reason**: 캘린더에 PRD 리뷰가 잡혀 있고, 제출 마감 전까지 피드백 반영이 필요해서 미리 준비가 필요해요.
- **warn**: 대기 중: PRD 리뷰(9/15) 결과 기다리고 있음 / 제출 마감 9/16 18:00 — 리뷰 지연 시 일정 조정 필요. 멘토 미팅(9/17)에서 추가 피드백 가능성도 있어요.
- **reason**: 캘린더: PRD 리뷰(9/15)·제출 마감(9/16)·멘토 미팅(9/17) / 드라이브: 기획안 초안·9월 회의 메모·진행 현황

### 3-3. "MABC 2027 충돌"
- **상태**: 확인 필요(기록 충돌)
- **kind**: 검토/의사결정 대기 업무
- **stateText**: 캘린더에는 PRD 리뷰(9/15)·제출 마감(9/16)·멘토 미팅(9/17) 일정이 잡혀 있는데, 드라이브 '진행 현황' 문서와 '기획안 초안' 문서 간 진행 상태 표기가 달라요. 어느 기록이 최신인지 확인이 필요해요.
- **action.line**: 캘린더 일정과 드라이브 문서(기획안 초안·진행 현황)를 대조해서, 현재 실제 진행 상태를 하나로 정리한 뒤 재개하세요.
- **action.reason**: 캘린더(일정)와 드라이브 문서(진행 현황) 간 상태 표기가 달라서, 최신 기록을 먼저 확인해야 다음 행동을 정할 수 있어요.
- **warn**: 충돌: 캘린더에는 PRD 리뷰·제출 마감 일정이 잡혀 있음 vs 드라이브 '진행 현황' 문서에는 다른 진행 상태 표기. 둘 중 어느 쪽이 최신인지 확인 전엔 상태 단정 불가. PRD 리뷰(9/15)·제출 마감(9/16 18:00) 일정은 캘린더 기준.
- **reason**: 캘린더: 기획 회의(9/10)·PRD 리뷰(9/15)·제출 마감(9/16)·멘토 미팅(9/17) / 드라이브: 기획안 초안·9월 회의 메모·진행 현황·업무 추적 — 문서 간 상태 표기 차이 있음

## 4. (test) 계열 질문 매핑

데모 영상용 질문으로 함께 사용할 수 있게, MABC 2027 (test) 계열 질문도 3종 시나리오 중 하나로 매핑됨.

| 질문 | 매핑 시나리오 |
|---|---|
| `MABC 2027 (test) 기획안 관련 뭐 했더라?` | 진행 중 |
| `MABC 2027 (test) 지금 바로 할 일 뭐 있지?` | 진행 중 |
| `MABC 2027 (test) 제출 일정 확인` | 대기 중 |

**매핑 로직 위치**: `api/generate.js` — `buildDemoResult(query)` 내,
```javascript
if (!key && query.includes("MABC 2027")) {
  if (query.includes("제출")) {
    key = "MABC 2027 대기 중";
  } else if (query.includes("기획") || query.includes("할 일") || query.includes("뭐 했")) {
    key = "MABC 2027 진행 중";
  }
}
```
→ `demoMap[key]`가 있으면 해당 카드 반환, 없으면 fallback.

## 5. 시연 흐름 (권장)

1. **입력**: MABC 2027 관련 질문 중 하나 입력 (예: "MABC 2027 진행 중")
2. **처리**: "기록을 정리하고 있어요…" + progress bar (900ms + 상태 전환)
3. **출력**: 업무 재개 카드 1장
   - 업무명: MABC 2027
   - kind: 검토/의사결정 대기 업무
   - 상태(state) + stateText
   - 첫 행동(action.line) + 근거(action.reason)
   - 주의사항(warn)
   - 근거 펼치기(reason) — 캘린더·Drive 기록 인용
4. **참고**: (test) 계열 질문도 동일 흐름으로 카드 출력됨 (매핑 결과)
