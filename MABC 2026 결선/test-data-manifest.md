## 통합 데모 흐름 (1막/2막/3막 — 상태 변화)

위 시나리오 A/B/C를 하나의 연속 흐름으로 엮은 데모 영상 구성. 시간의 흐름에 따라 업무 상태가 "진행 중 → 대기 중 → 확인 필요(충돌)"로 자연스럽게 전환되는 것을 캘린더(참고 캘린더)가 시간 축으로 묶는다.

### 흐름 개요

| 막 | 시간대 | 상태 | 캘린더(참고 캘린더) 역할 | 핵심 데이터 |
|----|--------|------|--------------------------|------------|
| 1막 | 9/10 (과거) | 진행 중 | 시간 기준점: 기획 회의 | 캘린더 + Docs + Gmail + Sheets 완료 |
| 2막 | 9/15~9/16 (현재/임박) | 대기 중 | 마감 트리거: PRD 리뷰 + 제출 마감 | 캘린더 + Gmail 알림 + Sheets 미완료 |
| 3막 | 9/15~9/16 (충돌 발견) | 확인 필요/충돌 | 캘린더와 다른 기록 간 시차/겹침 발견 | 캘린더 시각 vs Sheets 기한, 일정 겹침 |

### 1막: 복귀 후 "어디까지 했더라?" — 진행 중

**맥락:** 사용자가 복귀 후 서비스에 접속. 캘린더를 "참고 캘린더"로 연결한 상태에서, 최근 일정과 연결된 업무 기록을 재개.

**흐름:**
1. 첫 화면: "어디까지 했더라? 캘린더와 연결된 기록으로 바로 이어보세요." + "참고 캘린더: 4건 연결됨" 배지
2. 입력: "MABC 2027 기획안 관련 뭐 했더라?" (또는 예시 버튼 클릭)
3. 로딩: 캘린더에서 9/10 14:00 기획 회의 조회 → 같은 날 전후 Drive·Docs·Gmail·Sheets 조회
4. 카드 출력: "현재 상태: 진행 중 (9/10 회의 후 PRD 단계로 넘어감)"

**출력 카드:**
```
## MABC 2027 (test) - 기획안 관련 업무 재개
- 현재 상태: 진행 중 (9/10 기획 회의 후 PRD 단계로 넘어감) [사실]
  - 근거: Calendar 9/10 14:00 기획 회의 + Docs 9월 회의 메모 + Sheets "기획안 초안 작성" 완료
- 첫 행동: PRD 초안 작성 재개 (9/15 리뷰 미팅 전 정리)
  - 근거: Sheets "PRD 최종화" 미완료 (기한 9/16) + Calendar "9/15 PRD 리뷰" + Gmail PRD 리뷰 안내 메일
- 주의사항:
  - 9/15 14:00 PRD 리뷰 미팅 예정 → 그 전까지 초안 정리 필요 [사실]
  - 9/16 18:00 제출 마감 → 발표자료/포스터/데모 영상도 미완료 [사실]
  - 참고: 9/17 10:00 멘토 미팅 예정 [사실]
```

**캘린더의 역할:** 기획 회의(9/10 14:00)가 시간 기준점이 되어, 같은 날 전후 Drive·Docs·Gmail·Sheets 데이터를 "기획 회의 관련 기록"으로 통합. "참고 캘린더" 배지 표시.

**핵심 메시지:** "캘린더 일정이 흩어진 기록의 시간 기준점이 된다"

### 2막: 마감 임박 → "지금 바로 할 일" — 대기 중

**맥락:** 시간이 흘러 9/15~9/16로 전환. 제출 마감(9/16 18:00)이 다가오고, PRD 리뷰 미팅(9/15 14:00)이 예정됨. PRD 초안이 아직 미완료라 리뷰 결과를 기다리는 상태.

**흐름:**
1. 전환: "지금 바로 할 일 뭐 있지?" 또는 자연스럽게 시간 흐름 전환
2. 캘린더(참고 캘린더): 9/15 14:00 PRD 리뷰, 9/16 17:00 제출 마감 확인
3. Gmail: PRD 리뷰 안내 메일 + 마감 D-1 안내 메일 확인
4. Sheets: "PRD 최종화" 미완료, "발표자료" 미완료, "데모 영상" 미완료 필터링
5. 카드 출력: "현재 상태: 대기 중 (9/15 PRD 리뷰 미팅 결과 기다리는 중, 초안 정리 필요)"

**출력 카드:**
```
## MABC 2027 (test) - 지금 바로 할 일
- 현재 상태: 대기 중 (9/15 PRD 리뷰 미팅 결과가 오면 반영, 초안 정리 필요) [사실]
  - 근거: Calendar 9/15 14:00 PRD 리뷰 + Gmail "PRD 초안 리뷰 미팅 안내" 메일 + Sheets "PRD 최종화" 미완료
- 첫 행동: PRD 초안 완성 (9/15 14:00 리뷰 미팅 전 정리)
  - 근거: Sheets "PRD 최종화" 미완료 + Calendar "9/15 PRD 리뷰" + Gmail PRD 리뷰 안내 메일
- 주의사항:
  - PRD 초안: 미완료 (기한 9/16) → 오늘/내일 중 착수 필요 [사실]
  - 발표자료: 미완료 (기한 9/16) → PRD 확정 후 이어서 작업 [사실]
  - 데모 영상: 미완료 (기한 9/16) → 실제 동작 화면 촬영·편집 필요 [사실]
  - 9/16 17:00 제출 마감 (캘린더) → 18:00 제출 마감 임박 [사실]
  - Gmail: "제출 마감 D-1 안내" 메일 확인됨 (스레드 `1a099a532bf26e22`) [사실]
  - 9/17 10:00 멘토 미팅 → PRD/발표자료 초안은 가져가야 함 [사실]
```

**캘린더의 역할:** 캘린더의 9/15 PRD 리뷰 + 9/16 제출 마감이 "대기 중" 상태의 트리거. 마감 시각(17:00)이 Sheets 기한(9/16)과 함께 대기 상태를 구체화하고, Gmail D-1 메일이 마감 인지 상태를 보강.

**핵심 메시지:** "캘린더 마감 + 시트 진척 + 메일 알림 → 지금 뭘 해야 하는지"

### 3막: 충돌/확인 필요 — 캘린더와 다른 기록 간 시차·겹침 발견

**맥락:** 2막 상태에서 캘린더 일정과 Sheets·Gmail 기록 사이에 미세한 불일치/시차/겹침이 발견됨. 캘린더를 "참고 캘린더"로 쓰다 보니, 캘린더 이벤트와 다른 서비스 기록 간 상태 차이가 드러나는 케이스.

**사례 1: 캘린더 마감 시각과 Sheets 기한 표기 간 시차**
- 캘린더: 9/16 17:00~17:30 "제출 마감" 이벤트 (시각 포함)
- Sheets: "제출 양식" 항목, 기한 "2026-09-16" (날짜만, 시각 없음)
- 캘린더 마감 시각(17:00)과 Sheets 기한(날짜만) 간 시차 존재
→ "참고 캘린더의 마감 시각(17:00)과 Sheets 기한(날짜만) 간 시차 확인 필요" → 확인 필요/충돌

**사례 2: 캘린더 리뷰 일정과 Sheets 연동 테스트 기한 겹침**
- 캘린더: 9/15 14:00~15:00 "PRD 리뷰" 이벤트
- Sheets: "Google MCP 연동 테스트 ((test))" 항목, 상태 "(test) 진행 중", 기한 "2026-09-15"
- 둘 다 9/15로 겹침: PRD 리뷰 미팅과 연동 테스트가 같은 날
→ "캘린더 PRD 리뷰(14:00)와 Sheets 연동 테스트 기한이 같은 날(9/15) — 우선순위/시간 배분 확인 필요" → 확인 필요

**흐름:**
1. 2막 상태에서 Sheets/캘린더 데이터 교차 확인 중 불일치 발견
2. 충돌/시차 내용을 주의사항에 표시 (하나로 덮지 않고 모두 표시)
3. 카드 출력: "현재 상태: 확인 필요 (캘린더 마감 시각과 Sheets 기한 간 시차, 리뷰 일정과 연동 테스트 기한 겹침)"
4. 첫 행동: "충돌/시차 해소 후 재개" 방향 제시

**출력 카드 (충돌/확인 필요):**
```
## MABC 2027 (test) - 제출 일정 확인 필요
- 현재 상태: 확인 필요 (캘린더와 Sheets 간 일정 시차/겹침 발견) [확인 필요]
  - 캘린더: 9/16 17:00~17:30 "제출 마감" (시각 포함)
  - Sheets: "제출 양식" 기한 2026-09-16 (날짜만, 시각 없음) → 시차 확인 필요
  - 캘린더: 9/15 14:00~15:00 "PRD 리뷰"
  - Sheets: "Google MCP 연동 테스트 ((test))" 기한 2026-09-15 → 같은 날 겹침 확인 필요
- 첫 행동: 캘린더 마감 시각과 Sheets 기한 간 시차 확인 + 9/15 PRD 리뷰와 연동 테스트 우선순위 정리
  - 근거: 캘린더 이벤트 2건 + Sheets "제출 양식"/"MCP 연동 테스트" 행, 둘이 서로 다르게 보임
- 주의사항:
  - 캘린더 마감 시각(9/16 17:00)과 Sheets 기한(9/16 날짜만) 간 시차 있음 → 어느 쪽이 최신/정확한지 확인 필요 [확인 필요]
  - 9/15 PRD 리뷰(14:00)와 연동 테스트 기한이 같은 날(9/15) → 시간 배분/우선순위 확인 필요 [확인 필요]
  - 충돌/시차는 하나로 덮어 판단하지 않고 모두 표시 [규칙]
```

**캘린더의 역할:** 캘린더를 "참고 캘린더"로 쓰면서, 캘린더 이벤트(시각 포함)와 Sheets 기록(날짜만/기한) 사이에 시차·겹침이 드러남. 캘린더가 단순 일정 나열이 아니라, **다른 기록과의 비교를 통해 상태 불확실성을 발견하는 도구**로 작용.

**핵심 메시지:** "참고 캘린더로 흩어진 기록의 시간 기준을 맞춰보니, 캘린더와 Sheets 간 시차·겹침이 보였고, 그걸 확인 필요/충돌로 surfaced한 사례"

- 3막에서 충돌 내용(캘린더 시각 vs Sheets 날짜만, 일정 겹침)을 주의사항에 "모두 표시"하는 모습을 보여주면 규칙 준수(충돌 하나로 덮지 않기)도 입증됨
- "(test)" 표기와 "참고 캘린더" 배지로 실제/데모 구분을 명확히
